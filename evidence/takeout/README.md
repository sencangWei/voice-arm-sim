# 从盘子取出物品 — 2026-10-24

原问题：指令“把香蕉从盘子里面取出来”被只支持放入托盘的验证器拒绝，控制器也没有取出分支。本次新增明确的取出动作，无需重新训练模型。

未指定落点时，控制器从当前 RGB-D 图像寻找桌面空位；确认目标在盘子内后，真实夹取、搬运、松手，并用新图像核对结果。桌面空间不足或指令含不支持的复合动作时要求澄清，不猜测执行。

- `native-demo.mp4`：实际中文桌面面板与 MuJoCo 原生窗口并列录屏，先放入香蕉，再点击取出。55 秒、20 fps，无合成语音音轨。
- `native-result.json`：真实 Qwen 视觉定位与 RGB-D 控制结果。放入392控制步、21.23秒；取出359控制步、19.62秒，均成功。
- `put_in.png` / `take_out.png`：这两次任务的实际原生窗口截图。
- `color-results.json`：三个布局种子42/7/99 × 香蕉/苹果/方块，9组真实放入→取出全部通过。仿真真值只用于执行后的独立评分，不参与控制。

验证：30项测试通过；录像完整解码通过。9组为固定小范围回归，不代表任意家庭场景成功率。真人麦克风识别仍需实际使用验证；本次原生按钮通过文字提交指令。
