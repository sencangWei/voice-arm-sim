# 薄盒抓取修正与组合指令复测（2026-10-26）

本轮修复了一个可复现的抓取偏心问题，**没有解决全部抽屉任务**。使用 Qwen3-VL 理解指令、当前 RGB-D 定位及 OSC 控制；不是端到端 VLA，没有重新训练模型。

## 查到什么

1. **夹爪撞盘沿**：原算法取可见点云最高 35% 的点计算抓取中心。薄盒不到 1 mm 的倾斜就使这部分点偏在高侧，抓取点偏移约 1 cm。改为对靠近桌面的薄物体取顶部 3 mm 高度带，保留完整顶面。厚物体继续使用原算法。
2. **抽屉放入仍被拦截**：抓取修正后能抬起盒子，但抽屉底面候选中没有通过当前净空检查的落点。盒子估计占用半径加余量为 57.6 mm，候选点最大障碍距离约 52.4 mm。因此持有盒子停止，没有松手、没有执行后续关抽屉。这个检查是保守的二维近似，不是“物理上绝对放不下”的证明；下一步需要狭窄空间的朝向、夹爪及进入路径规划，不能仅缩小余量冒充修好。
3. **完成判定漏报**：盒子已由盘子搬至灶台且松手，独立物理观察器判定在灶台上，但视觉模型称“未明确识别蓝色奶酪盒”。两次对相同画面复核仍不确定，随后停止。此项尚未修复。
4. **连续抽屉上下文不足**：下一条独立指令要求打开已打开的抽屉时，现有三层把手定位没有通过，未发动作。前一条也没有成功放入盒子，所以本轮不能声称验证了抽屉取物。

本轮没有执行到控制步数上限或超时；失败原因分别是净空检查、视觉完成判定和抽屉状态处理。大模型能重新规划，但必须有能执行且可验证的底层技能，重新询问同一画面不会自动修好这些技能。
