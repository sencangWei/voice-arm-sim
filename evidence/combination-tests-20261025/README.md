## 后续修复应优先处理什么

1. 盘子“里/上”的目的地类型统一：完整规划与单步任务接口必须采用相同关系契约；先修接口一致性再重复抓放。
2. 抽屉层级定位：目标层与实际把手高度需相互核对，同时改善遮挡后的重新观测；不能仅因一个抽屉动了就判断指定抽屉完成。
3. 扁薄奶酪盒的抓取可达性与接触脱离：目前抓取点不收敛后，恢复选择反复 reverify，没有改变抓取姿态。
4. 恢复的动作选择：几何错误和JSON/契约错误应采取不同恢复措施，仅重新观察同一画面不会自动修好它们。

本轮只新增测试脚本与证据，未修改上述产品行为。现有证据不足以支持直接引入强化学习；应先解决可确定的接口、定位和控制问题，再评估是否需要训练。
