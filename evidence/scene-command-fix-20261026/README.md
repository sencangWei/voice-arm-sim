# 2026-10-26 场景菜单引发的直接失败

用户在中文面板选取“打开炉灶”，动作前 HTTP 400：`计划状态与缺失技能矛盾`，控制步数为 0。
菜单实际是 LIBERO 官方任务场景列表，当前执行器没有炉灶旋钮技能。Qwen 明确返回 unsupported，但空 missing_skills 被当作异常。

## 修改

- 接受有明确原因的 unsupported 返回；非 ready 计划保持零运动。ready 的技能、目的地和缺失技能校验继续保留。
- 规划提示补充 unsupported 示例；场景选择不再改写用户指令，面板明示已接入与未接入技能。
- 没有添加旋钮控制，没有更换模型、训练权重或通过写仿真关节状态伪造完成。

## 验证

两个新增回归测试在修改前均失败；修改后，计划、模型服务和工作台相关测试共 74 项通过。
Ruff 基础错误/未定义名检查 E9,F 和 Python 编译通过；仓库默认完整 Ruff 仍有既有风格告警，不声明完整 lint 通过。
